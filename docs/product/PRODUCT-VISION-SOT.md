> 본 file = GB(호흡)·GD(일상)·GT(식단) 3 앱 공통 상위 헌법. 자식 기획안(docs/plan/기획안_보강.md)·Design SoT·구현은 본 문서 정합 의무. 신설 = MASTER-VISION-SOT-001 (2026-06-06 KST · 사용자 본심 직접 외화).

## §0. 도메인 정의

**문제 인식**: 높아진 문화 수준이 높은 이상·기준을 내면화시키고, 자기 실제 수준과의 격차에 적응하지 못한 사람들이 쉽게 포기한다.

**도메인 정의 (단일 문장)**: **기준은 사용자 실측 행동에서만 나온다.** 높은 이상·외부 권장·타인 비교에 기준을 맞추게 하지 않고, 자신이 할 수 있는 기준을 받아들인 뒤 조금씩 넓히거나 높여가게 한다.

기존 공통 UX 톤("느슨한 동행 · 판단 없는 위로 · 작은 변화 축하")의 상위 근거 = 본 정의.

## §1. 동기부여 원칙 6항

동기부여는 필요하다. 단 기준의 출처와 난이도를 아래 6항으로 제한한다.

1. **비교 대상 = 과거의 자기 자신만** — 타인 비교·랭킹·퍼센타일 영구 금지.
2. **기준선 = 실측 baseline** — 목표를 이상("주 7회")이 아닌 사용자 최근 행동에 앵커. 상향 = 최소 단위 + 사용자 동의 시만.
3. **grow-only 지표** — 누적형(끊겨도 감소·리셋 X)만 사용. streak 등 리셋형 지표 금지.
4. **복귀 = 축하 이벤트** — 공백 후 재방문을 실패가 아닌 성취로 프레임.
5. **하향 = 성공** — 목표 낮추기에 부정 프레임 금지 (자기 기준 수용의 직접 구현).
6. **자극 장치 금지** — loss aversion 푸시·죄책감 카피·사람을 바꾸려는 수준의 난이도 금지. 가볍게 접근 가능하고 작은 변화에 적응해 갈 수 있는 난이도만.

## §2. 5영역 적용 원칙 (= 정합 audit 판정 기준)

| 영역 | 원칙 |
|---|---|
| 온보딩 | 초기 기준 = 현재 수준 입력. 이상·권장 기준 제시로 시작 금지 |
| 목표 설정 UX | 목표 출처 = 사용자 실측/직접 선택 · 기본값 = 보수적(낮게) |
| AI 코칭 카피·톤 | "권장 기준 대비 미달" 화법 금지 · 본인 기준·본인 변화 화법만 |
| 리포트 프레이밍 | 누적·자기비교 프레임 · 목표 대비 미달 % 프레임 금지 |
| 동기부여 지표 | §1 6항 전면 적용 · streak/달성율%/배지/챌린지/레벨 금지 |
