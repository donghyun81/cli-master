## 5. 본 회차가 rule 을 실제로 문 자리 3

1. ★**rule §2「정본을 못 찾으면 등재 금지」가 뒤집혔다.** 발주 초안은 §A 소계 갈림을 「⑴ 표 밖 prose 멤버인지 ⑵ 소계 오계수인지 미판정 = 정본 없음」으로 **기각**했다. 층을 갈라 세니 정본은 **제3의 것**(표 **안**의 박제 2행 +2 · 표 **밖** prose 멤버 −1)이었다. rule §2 는 「모르면 등재 금지」이지 **「세지 말라」가 아니다** ⟹ 기각을 뒤집어 **OPEN 으로 등재**했다.
2. ★**같은 갈림이 「이 회차의 고침 때문에」 비로소 위험해졌다.** §D-5 의 자가 죽어 있을 때(출력 6)는 소계 49 가 아무것도 오도하지 않았다. 자를 고쳐 살리는 순간 그 자는 §A 멤버 수 = **48** 을 요구하고, 소계로 세면 **49** → **1 갈림 false DRIFT**. **정정이 새 결함을 여는 경로**이므로 같은 cycle 안에서 등재해야 했다.
3. ★**rule §1 「이력은 대상 밖」이 두 번 갈랐다.** ⓐ `propagation-status.md:8` = 소속 절 heading 이 `## 수기 sha 매트릭스 폐기 (…2026-06-01)` = **규범 절**이고, 같은 file 의 이력 절은 `## <CYCLE-ID> 마감 (date)` 형태로 **따로 4개** 있다 ⟹ 오등재 아님. ⓑ 박제 2행 자체는 **삭제 금지**(이력) — 대상은 그 박제가 아니라 **그것을 세는 소계**다.
